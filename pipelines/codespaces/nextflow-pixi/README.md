# Codespaces Nextflow Pipeline (pixi)

This directory contains a bash script that sets up and runs a Nextflow pipeline using Pixi in GitHub Codespaces.

## 🚀 Quick Start

```bash
# Run the setup and pipeline script
./run.sh
```

## Manual Usage

Make sure pixi is installed.

```bash
pixi run --manifest-path ../../shared/nextflow/version_check/pixi.toml pipeline
```
